## 🌸 Descripción

Esta práctica consiste en el **modelado de sistemas físicos** utilizando herramientas como **Matlab, Simulink y Simscape**.

El sistema estudiado corresponde a un **disco rodante unido a un resorte lineal**, cuyo comportamiento dinámico se analiza mediante simulaciones que representan variables como **la velocidad y la posición del motor**.

---

## 🌷 Objetivo

🌸 Comprender el comportamiento de **sistemas físicos**
🌸 Aplicar **modelos matemáticos** a sistemas dinámicos
🌸 Analizar la respuesta del sistema mediante **simulación computacional**
